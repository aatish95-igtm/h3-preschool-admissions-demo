From preview to WhatsApp

Try it in a real conversation.

This preview is ready to present. A WhatsApp test needs a connected messaging account and a public, secure server.

  1. Activate a Twilio WhatsApp test environment. Use “Try out WhatsApp” in the new Console, or the Sandbox in the legacy Console.
  2. Connect the included server. Add the private account token and the exact public HTTPS webhook address. The setup guide explains each step.
  3. Join from your phone. Follow Twilio’s join instructions, then send “Hi” and try the same admission flow.
The Sandbox uses Twilio’s shared number and logo. H3’s own identity requires a registered WhatsApp sender. This demo does not send enquiries to school staff.
